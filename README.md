# intheinsucolabs.com

## Descripción

Sitio web informativo sobre los laboratorios del Instituto Superior de Comercio de Valparaíso. Este sitio permite conocer información de los cinco laboratorios del establecimiento, como la cantidad de computadores, sistema operativo y su disponibilidad.

## Objetivo del proyecto

Crear un sitio web atractivo, funcional y adaptable a diferentes tamaños de pantalla para facilitar el acceso a la información de los laboratorios.

## Tecnologías que se usaron

- HTML
- CSS
- Diseño Responsive

## Páginas del sitio

- Inicio
- Laboratorios
- Laboratorio 1
- Laboratorio 2
- Laboratorio 3
- Laboratorio 4
- Laboratorio 5
- Sobre nosotros
- Contacto
